Angel's vector master is original code-authored artwork shared unchanged with the native iPhone app. `angel-vector.json` has SHA-256 `805783c577c0beb332256fd8786fefa6b42d8a24a2f499b4e1a3de9e26f7f1e0` and 149 shapes. It contains no other character's pixels.

`angel-motion.mjs` follows the native `CharacterAngelVectorMotion.swift` geometry: seventeen faces, nine mouth roles, continuous clipped eyelids, slow wings, floating halo and dimming jewels at stable positions. The web rig consumes the existing voice-message audio clock, RMS envelope, viseme selection and motion policy. It creates no timer and does not control audio. ID and avatar filename must both match the public Angel record.

Standard WebSocket calls pair the bridge's version-1 character metadata with each scheduled WAV clip, and classic calls use the selected agent plus authored leading voice cues. Both consume the existing output analyser, playback clock and portrait renderer; ownership follows the clip actually playing rather than early server state. Pausing, barging in, hanging up or leaving the call invalidates queued presentation. Spotter/Gemini LIVE audio keeps the generic live orb because it has no prepared character identity.

When animation is paused, disabled, reduced, hidden or unavailable, the server avatar remains the fallback. Localized appearance descriptions and audio/call controls remain accessible. Validation includes pure motion/ownership tests, real Canvas geometry captures, service-worker click tests and production bundle builds. These checks do not establish physical iPhone or browser microphone/playback behavior.
